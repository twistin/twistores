KAIROS abre su cartografía de referencias sonoras

Esta página no documenta un patch ni una sesión, sino el ecosistema de escucha que rodea el proyecto: artistas, escenas y afinidades organizados por ámbitos, con una firma gráfica para cada orientación sonora.

Esta cartografía funciona como archivo de referencias para KAIROS y como mapa de escucha para el laboratorio. No es una lista enciclopédica: es un registro vivo de artistas que ayudan a pensar timbre, forma, espacialización, ruido, sistemas y escucha profunda desde distintos ámbitos.

Función: recurso de apoyo e investigación dentro del laboratorio.

Estructura: artistas agrupados por ámbitos y representados con una firma espectral sintética.

Uso: brújula estética para KAIROS, Deriva y las próximas sesiones de síntesis.

Cómo ampliar este registro
Añade un objeto al array ARTISTAS en el código de esta página y vuelve a abrirla.
Campos: nombre, alias, origen, anios, ambito, firma, estilo, tags, sc (true si usa SuperCollider), relevancia.
Ámbitos: micro · acus · code · club · ruido · Firmas: data · sparse · pulso · grano · grid · curva · drone · caos · decaer · niebla · campo · ruido.
