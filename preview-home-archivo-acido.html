Esta maqueta no modifica la web principal. Sirve para ver cómo se comporta `Archivo Ácido` cuando ya no se presenta como paleta abstracta sino como una home plausible de TWISTORES. Mi juicio sigue siendo el mismo: es la opción más memorable, pero pide control editorial para no saturar.
